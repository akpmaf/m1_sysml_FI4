# m1_sysml_FI4 - Systeme de detection de feux de foret
## Description breve du systeme
Le systeme detecte un depart de feu en foret (fumee ou point chaud) des ses premiers instants
et transmet l'alerte a distance aux services de secours. Il repose sur des dispositif de detection autonomes (capteurs; balises; camera) installes en milieu naturel, alimentes par energie solaire, qui communiquent a distance (par radio longue portee;internet) avec une passerelle chargee de relayer l'alerte. Un operateur installe le systeme et surveille son etat.
